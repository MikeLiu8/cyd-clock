已有 BIN？使用另一個網頁燒錄工具

Mike 亦曾使用 Spacehuhn ESPWebTool 燒錄裝置。先下載完整 v19 BIN，用電腦 Chrome／Edge 開啟工具，經一條資料 USB 線連接 CYD，選擇此檔並將起始位址填 0x0（0），依提示完成寫入後重開。

這是完整合併 BIN，包含開機及分區資料，不能把整個檔案寫到 0x10000，亦毋須另加其他 segment。燒錄會取代原程式；全 Flash 擦除亦會清除 Wi-Fi、收藏及設定，請先保留資料。兩個安裝入口選用其中一個即可；v19 經此工具的全新裝置安裝仍未獨立驗收。

03 / 首次設定

設定你自己的 Wi-Fi、天氣及巴士

  1. 裝好 SD 卡並開機，查看 CYD 畫面上的設定網絡名稱及六位 PIN。
  2. 用手機或電腦連接 CYD-Setup-XXXX。Wi-Fi 密碼是 CYD- 加六位 PIN，不是只有六位數字。
  3. 開啟 http://192.168.4.1/，在設定網頁輸入六位 PIN，設定你的 2.4 GHz Wi-Fi。
  4. 連線後，改回家中 Wi-Fi；在 CYD 手動設定頁查看網址或掃 QR Code，修改天氣測站及三個巴士收藏。巴士選用站點後，記得按「儲存目前設定」，並確認「已儲存及讀回核對」。

PIN 每次重開會改變。天氣預報為香港整體，首頁氣溫使用所選測站；資料未取得時不會顯示虛構結果。

使用及常見問題

怎樣切頁及進入工具？

自動輪播首頁、聖經及交通三頁。左右輕按可手動切到第四頁倒數工具；中央長按約1.5秒固定本頁，再長按解除；左右切頁會解除固定。工具及設定頁不會自動跳走；倒數頁按「設定」直接顯示網址／PIN／QR，右上有 IGNITE Logo。首頁點天氣圖示查看明天／後天預報，輕按金句帶可暫停／繼續。

怎樣啟用夜間模式？

第四頁「設定」→用手機／電腦開啟網址或掃QR→輸入PIN→「讀取目前設定」→「顯示與夜間模式」，勾選「啟用定時夜間模式」並儲存。預設未啟用，夜間時段為香港時間22:00–07:00，可修改。日間為米白底、夜間為深色底，背光亦可分別調整；不是環境光感應。

巴士偶爾顯示「更新失敗」？

目前已知第2／3收藏有時會暫時更新失敗，之後自行恢復；根本原因尚未確認。請勿把試用版到站時間當成保證；仍應以巴士公司的最新資訊為準。

USB 找不到裝置或顯示不正常？

先確認資料線及板型。若電腦要求 CH340 驅動，從晶片廠商的官方網站取得適合你的系統的版本。若顯示方向、顏色或觸控位置不正確，停止操作並確認硬件 revision，這個韌體未驗證其他控制器或不同板型。

安裝頁會收集我的 Wi-Fi 密碼嗎？

Wi-Fi 在 CYD 自己提供的設定網頁輸入。本安裝頁沒有分析追蹤程式，不要求 PIN 或 Wi-Fi 密碼；安裝按鈕從 CDN 載入 ESP Web Tools。公開下載是編譯韌體及準備好的 SD 內容，不是開發板的 Flash／NVS 設定備份。
